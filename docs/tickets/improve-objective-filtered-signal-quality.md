# [improve-objective-filtered-signal-quality] 改善ループの目標を「選別可能な勝ち筋シグナル」に寄せる (PF ≥ 1.0 を床に)

**状態**: 設計待ち / **優先**: 中

## 現象

現行の採用 gate は holdout の収益指標で戦略単体を裁くが、最終判断は LLM が行うので、戦略 plugin の役割は「候補シグナルを出すこと」である。2026-10-07 ユーザー方針: 改善の目標は「発火したシグナルの中に、決定論的な根拠タグで見分けのつく勝ちやすい部分集合があること」とし、全体収益の最大化は目標にしない。ただし若干の負けを許すと改善が怠ける恐れがあるため、バックテストの全体 PF ≥ 1.0 (損をしない) を最低目標の床として残す (ユーザー裁定)。否定材料として挙がった点: 部分集合は後付けで必ず見つかる (選択バイアス) / 優位性が LLM の版に紐づき再現不能 / 損失の帰属が戦略と選別で分離できない / 選別が劣化すると既定が負になる / 選別後の期待値は発注がないと測れない (ペーパーの発注は 9/21 の 1 件のみ)。対処の骨子: (1) 戦略出力に決定論的な根拠タグ・強度を持たせ、副目標を「タグ別期待値の分布 (上位タグが正)」にする、(2) ペーパー運用で シグナル → LLM の採否 → 結果 を台帳に残し「選別後の期待値」を計測する (最低サンプル数と out-of-sample の規律を決める)、(3) 採用 gate は PF ≥ 1.0・drawdown・最大連敗を床として残し、利益目標は外す。PF < 1 の許容は (2) が十分な件数で測れてからの再裁定。着手はウィザード完了後 (道筋優先)。
